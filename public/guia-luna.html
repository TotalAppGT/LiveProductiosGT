📤 CARGA MASIVA DE TAREAS (Excel)

En la web, pestaña Tareas → botón 📥 Plantilla XLSX (descarga) y 📤 Cargar masiva (subir).

  • La plantilla trae 3 hojas: Plantilla, Usuarios (nombres exactos) y Valores (opciones válidas).
  • Columnas: titulo, asignado_a (nombre exacto), categoria, tipo (FIJA/DINAMICA), frecuencia, dia_semana, fecha (YYYY-MM-DD), hora (HH:MM), prioridad.
  • Para tareas fijas (ej. "revisar chat de pagos cada lunes"): tipo=FIJA, frecuencia=SEMANAL, dia_semana=LUNES, dejar fecha vacía.
  • Para tareas variables (puntuales): tipo=DINAMICA y llenar fecha (y hora si aplica).
  • Borrar la fila de ejemplo antes de subir. Se aceptan fechas DD/MM/AAAA también. Las tareas duplicadas (mismo título y asignado) se omiten automáticamente.

🖥️ VISTA WEB DE TAREAS (tipo Excel)

La pestaña Tareas se organiza por Fase → Día → Fijas/Variables:

🎪 PRE EVENTO 📅 Lunes 🔁 Fijas (3) ⚡ Variables (2) 📅 Martes 🔁 Fijas (1) 🚀 EVENTO 📅 Sábado ⚡ Variables (2) 🏁 POST EVENTO 📅 Lunes 🔁 Fijas (4)
  • Botón + en cada fase o segmento → inserta una nueva fila/tarea ahí.
  • Filtros: 🎪 Pre Evento / 🚀 Evento / 🏁 Post Evento, y 🔁 Fijas / ⚡ Variables.
  • Botón "Por Día" → cambia a vista agrupada solo por día (Lunes-Sábado).
  • Acciones por fila: ✓ completar, ↑↓ subir/bajar (reordenar), ✏️ editar, ▶ en proceso, ⏰ posponer, 💬 comentar, 🗑 eliminar.
  • Al completar una tarea, se quita del listado; si es fija, se regenera para su próxima semana/mes.
  • Debajo de las tareas aparecen los bloques de ⏰ Recordatorios y 🛒 Compras, todos ordenados por día y hora.
